# Delt Dynasty Hub

A static recap site for the Delt Dynasty fantasy football league with three surfaces:

1. **Wrapped pages** — per-season awards (`/wrapped/2024`, `/wrapped/2025`)
2. **2026 Live Dashboard** — auto-detects pre-draft / drafted / in-season state (`/2026`)
3. **AI Weekly Recaps** — savage, league-context-aware roasts written by Claude Opus 4.7 (`/recaps`)

## Stack

- Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 3.4
- Sleeper API (no auth) for league data
- `@anthropic-ai/sdk` for AI-generated recaps with prompt caching

## Local development

```bash
npm install
npm run fetch-data   # writes data/season_*.json + data/players.json
npm run dev          # http://localhost:3000
```

## Generating AI recaps

You need an Anthropic API key with credits loaded. Save it locally:

```bash
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env.local
```

Then:

```bash
# One specific week
npm run generate-recap 2025 14

# All completed weeks across all seasons (skips weeks already generated)
npm run backfill-recaps

# Force-regenerate everything
npm run backfill-recaps -- --force
```

Recaps land in `data/recaps/<year>-w<week>.json` and are checked into git so the deployed site has them. The script uses Claude Opus 4.7 with adaptive thinking and prompt caches the league context (team names, owners, player nicknames) at 0.1× cost.

## Build

```bash
npm run build        # auto-runs fetch-data first
npm start
```

## Deploy

```bash
npx vercel deploy --prod
```

The Vercel build runs `fetch-data` automatically. AI recaps are NOT regenerated at build time (would burn API cost on every deploy) — they're committed JSON and read at build time. Regenerate locally and redeploy for new recaps.

No env vars are required on Vercel for the basic site. Only set `ANTHROPIC_API_KEY` there if you wire up a Vercel Cron / serverless function for auto-generation.

## Adding a new season

The fetch script auto-traces `previous_league_id` chains. When Sleeper rolls your league into the next year just rerun `npm run fetch-data`. Wrapped pages auto-appear for any season with `status: "complete"`.

## Tuning the recap voice

The system prompt and league context live in `scripts/generate-recap.ts` and `src/lib/weekly.ts`. Edit either, then `npm run backfill-recaps -- --force` to regenerate everything in the new tone.
